# 🛠️ Skill Swap Platform – Odoo Hackathon 2025

A fully functional web app for skill exchange using React, Firebase, and Tailwind CSS.

## Features
- 🔐 Firebase Authentication
- 📬 Real-time Chat
- 📊 Skill Trends (Admin only)
- 📁 CSV Export
- 🌙 Dark Mode, Responsive

## Setup
1. Clone the repo
2. Add your Firebase config to public/index.html
3. Run: `npm install && npm run dev`
